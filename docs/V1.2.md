# Oliveira DevCloud v1.2 — Automatic Workspace Provisioning

## Entregue
- `@oliveira/setup-engine` para detectar stack dentro do container.
- Detecção: Next.js, React/Vite, Node.js, Spring Boot Maven/Gradle, Python e Docker.
- Detecção de npm/pnpm/yarn e instalação automática quando suportada.
- Portas sugeridas por stack e registro em `WorkspacePort`.
- `POST /api/v1/setup/quickstart` cria o workspace Docker.
- `GET /api/v1/setup/:workspaceId/detect` inspeciona o projeto.
- `POST /api/v1/setup/:workspaceId/provision` clona, detecta, instala, registra previews e inicia code-server.
- Wizard `/onboarding` agora executa o fluxo completo e termina em **Workspace Ready**.
- Imagem `infra/workspace-images/node/Dockerfile` adicionada (estava ausente no ZIP v1.1) com Node 22, Git, tmux, Python, Java 17, Maven, pnpm/yarn e code-server.

## Limites conhecidos
- O provisionamento ainda é síncrono; projetos grandes devem migrar para BullMQ na v1.3.
- Gradle depende do wrapper do próprio repositório.
- Python só instala automaticamente `requirements.txt`; `pyproject.toml` é detectado mas não assume Poetry/uv sem evidência.
- A descoberta de portas é baseada na stack nesta versão; descoberta de sockets/processos em runtime fica para a próxima etapa.
