# Oliveira DevCloud v0.4 — Terminal Persistente

## Entregue

- terminal web com `@xterm/xterm`;
- transporte bidirecional por WebSocket autenticado;
- attachment ao container do workspace via Docker Engine API;
- persistência de shell/processos com `tmux` dentro do workspace;
- reconexão sem matar a sessão quando o navegador fecha;
- resize dinâmico de TTY;
- limite inicial de 2 terminais ativos por workspace;
- registros `TerminalSession` no PostgreSQL;
- criação e encerramento auditados;
- validação de RBAC antes de listar, criar, conectar ou fechar terminais;
- payload de WebSocket limitado;
- nomes de sessão tmux validados e nunca interpolados em shell.

## Fluxo

Browser/xterm.js → WebSocket autenticado → API → Docker Exec TTY → `tmux attach` → shell do workspace.

Ao fechar a aba, somente o attachment é encerrado. A sessão `tmux` e seus processos permanecem no container. Ao reconectar, a API faz novo attachment à mesma sessão.

## Segurança

O navegador nunca recebe acesso ao Docker socket. A API valida a sessão do usuário, o vínculo com a organização e o workspace antes de criar o attachment. Os comandos do lifecycle de terminal são passados ao Docker como arrays de argumentos, sem concatenação de input em shell.
