# Oliveira DevCloud v1.1 — Product Experience

## Entregue
- Dashboard premium do control plane com métricas atualizadas a cada 5 segundos.
- Cards de workspaces, agentes, orquestrações e projetos.
- Uso de CPU/load e memória do host.
- Central de atividade baseada no AuditLog e protegida por membership da organização.
- Quick actions para Agents, Orchestrations, Terminal e Browser IDE.
- Wizard `/onboarding` para GitHub → Project → configuração sugerida.
- Command Center direcionando objetivos para o Orchestrator já existente.
- Layout responsivo para desktop e celular.

## Segurança
O endpoint de atividade exige sessão válida e membership na organização. Nenhum secret é retornado pelo dashboard.

## Próximo marco sugerido (v1.2)
- onboarding transacional que também cria e inicializa o workspace;
- detecção automática de stack (package.json, pom.xml, pyproject.toml etc.);
- métricas Docker por workspace em vez de apenas host;
- stream de atividade via WebSocket/SSE;
- notificações persistentes e action-required;
- testes E2E do fluxo GitHub → workspace → IDE → agent.
