# Oliveira DevCloud v1.5 — Command Center

## Entrega
A v1.5 adiciona um Command Center que transforma um objetivo em linguagem natural em um plano explícito de execução sobre o orquestrador já existente.

## Fluxo
1. O usuário seleciona um workspace e descreve o objetivo.
2. A API valida RBAC e inspeciona a stack real do container com `setup-engine`.
3. `command-center-engine` produz um DAG determinístico e auditável.
4. O plano é persistido em `CommandRun` e uma `Orchestration` é criada em DRAFT ou QUEUED.
5. No modo de aprovação, nenhum agente inicia antes do clique `Aprovar e iniciar equipe`.
6. A execução continua usando worktrees isolados, BullMQ, review integrado e aprovação humana já existentes.

## Transparência
O planejador v1.5 não chama um LLM escondido. A linguagem natural é classificada por regras simples e contexto da stack. Isso torna a primeira versão previsível e evita prometer uma camada de IA que ainda não foi integrada.

## Segurança
- RBAC DEVELOPER para planejar/iniciar.
- Nenhum comando shell vindo do texto do usuário é executado.
- Quality gates continuam restritos à allow-list do orquestrador.
- O objetivo é persistido para auditoria e reprodução.
- Agentes continuam isolados por Git worktree.

## Próximo marco
v1.6: planner opcional via provider configurável (OpenAI/Anthropic) com schema estruturado, validação do DAG, policy engine e fallback determinístico; eventos em tempo real do Command Center; estimativas e budgets por execução.
