# Oliveira DevCloud v0.5 — Web IDE & Application Preview

## Entregue nesta versão

A v0.5 adiciona a primeira IDE real do DevCloud, executada **dentro do workspace** e acessada por um proxy autenticado do control plane.

### Web IDE
- `code-server` instalado na imagem base do workspace.
- Inicialização/parada/status controlados pela API.
- IDE escuta somente na rede interna do container, porta `13337`.
- Nenhuma porta da IDE é publicada diretamente no host.
- A API resolve o IP interno do container e atua como reverse proxy.
- HTTP e WebSocket são encaminhados, permitindo o funcionamento do VS Code Web.
- O acesso ao proxy exige sessão válida e membership da organização.
- Eventos `IDE_STARTED` e `IDE_STOPPED` entram no AuditLog.

### Application Preview
- Registro explícito de portas HTTP por workspace.
- Faixa permitida: `1024..65535`.
- Porta `13337` reservada à IDE.
- Preview também passa pelo proxy autenticado.
- Não existe proxy aberto para uma porta arbitrária: a porta precisa estar registrada em `WorkspacePort`.
- Suporte de WebSocket no proxy para dev servers com HMR.

### Banco
Novos modelos:
- `IdeSession`
- `WorkspacePort`

### Frontend
Nova tela:
- `/ide?workspaceId=<id>`

Ela permite iniciar/parar a IDE, abrir o editor em iframe e registrar previews como `3000`, `5173` e `8080`.

## Modelo de segurança

O `code-server` roda com `--auth none` **somente porque ele não é exposto diretamente ao usuário**. Autenticação e autorização ficam no control plane. Não publique a porta 13337 do workspace no host nem crie regras externas apontando diretamente para ela.

O workspace continua como usuário `devcloud` (UID 10001), non-root, com `cap-drop ALL`, `no-new-privileges`, limites de memória/CPU/PIDs e filesystem persistente apenas sob `/workspace`.

## Build da imagem

```bash
docker build -t oliveira-devcloud/workspace-node:0.5 infra/workspace-images/node
```

O Dockerfile fixa a versão do code-server via `CODE_SERVER_VERSION`. Atualizações devem passar por revisão e rebuild da imagem.

## Migração Prisma

```bash
npm run db:generate
npm run db:migrate
```

Use o nome de migração sugerido:

```text
add_ide_and_workspace_ports
```
