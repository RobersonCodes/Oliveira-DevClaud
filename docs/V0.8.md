# Oliveira DevCloud v0.8 — Agent Orchestrator

A v0.8 introduz um orquestrador DAG para combinar tarefas CODEX, CLAUDE e gates SYSTEM.

## Fluxo
1. A API valida o plano, incluindo dependências desconhecidas e ciclos.
2. O plano é persistido como `Orchestration` + `OrchestrationStep`.
3. BullMQ publica ticks idempotentes para o worker.
4. Etapas AGENT recebem `AgentTask`, branch e Git Worktree próprios.
5. Etapas SYSTEM só executam comandos explicitamente allow-listed (`npm test`, `npm run build`, `npm run lint`, `npm run typecheck`).
6. Uma etapa só fica pronta quando todas as dependências concluíram.
7. Falha em qualquer gate interrompe o fluxo; sucesso total muda o plano para `WAITING_REVIEW`.

## Segurança
O MVP não aceita shell arbitrário em SYSTEM steps. O comando é validado contra uma allow-list. Prompts continuam isolados no agent-engine e cada agente trabalha em worktree próprio.
