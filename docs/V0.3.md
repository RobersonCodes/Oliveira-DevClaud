# Oliveira DevCloud v0.3 — Workspace Engine

## Entregue

- `@oliveira/workspace-engine` com contrato independente do backend.
- implementação Docker via Dockerode.
- lifecycle: create, inspect, start, stop, restart e destroy.
- API `/api/v1/workspaces` protegida por Organization RBAC.
- estados persistidos no PostgreSQL.
- quotas configuráveis de CPU e memória.
- `PidsLimit`, `no-new-privileges`, `CapDrop: ALL` e usuário non-root na imagem base.
- volume persistente por workspace.
- labels para rastreabilidade de container/project/workspace.
- AuditLog para operações de lifecycle.
- imagem `infra/workspace-images/node/Dockerfile` preparada para Node 22, Git e tmux.
- página `/workspaces` apresentando o control plane.

## Limite intencional desta versão

O Docker socket é um recurso altamente privilegiado. Em desenvolvimento ele pode ser montado somente na API/control-plane. Em produção, a recomendação é separar o executor de workspaces em serviço dedicado e não conceder acesso ao socket para o frontend nem para containers de usuário.
