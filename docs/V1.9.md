# Oliveira DevCloud v1.9 — Code Intelligence

A v1.9 adiciona um mapa semântico limitado do código: símbolos, endpoints HTTP e dependências locais. O analisador lê no máximo 140 arquivos de código e até 18 KB por arquivo, não lê `.env` e reutiliza o Repository Map filtrado. Snapshots são cacheados por `workspaceId + commitSha` somente quando o worktree está limpo.

## Endpoint

`GET /api/v1/code-intelligence/:workspaceId?refresh=true`

## Segurança

O recurso não executa código do repositório, não envia conteúdo bruto para o navegador além de assinaturas curtas e não concede shell aos agentes. A análise é heurística nesta versão; AST/Language Server pode ser introduzido posteriormente.
