# Oliveira DevCloud v0.2

## Entregue
- Sessões server-side com token aleatório, hash SHA-256 no banco e cookie HttpOnly.
- Senhas com bcrypt (cost 12).
- Rate limiting global e específico em login/registro.
- Bootstrap da primeira Organization no cadastro.
- RBAC OWNER / ADMIN / DEVELOPER validado na API.
- CRUD inicial de Projects com escopo por Organization.
- AuditLog para cadastro, login, criação e exclusão de projeto.
- Endpoints `/health` e `/ready`.
- UI mínima para Login/Registro e listagem real de Projects.

## Decisões de segurança
- O frontend não é fonte de verdade para autorização.
- Sessão é opaca; o token bruto não é persistido no PostgreSQL.
- Cookies usam HttpOnly + SameSite=Lax e Secure em produção.
- Exclusão de Project exige OWNER; criação exige ADMIN ou OWNER.
- Entrada é validada por Zod.
