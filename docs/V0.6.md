# Oliveira DevCloud v0.6 — AI Agents

Esta versão introduz a primeira camada operacional de agentes de IA dentro dos workspaces Docker.

## Incluído

- `@oliveira/agent-engine` com execução via Docker Exec + `tmux`.
- suporte aos provedores `CODEX` e `CLAUDE`.
- criação, início, status, logs e cancelamento de tarefas.
- `AgentRun` para histórico de execuções.
- painel `/agents?workspaceId=...` com polling de status e logs.
- CLIs Codex e Claude Code adicionados à imagem do workspace.
- auditoria de criação, start e cancelamento.
- prompts enviados por variável de ambiente para evitar interpolação direta em shell commands.

## Credenciais

A v0.6 não implementa ainda o Secret Manager. Para desenvolvimento local, autentique cada CLI dentro do workspace usando um terminal persistente ou injete as credenciais no ambiente do container de forma controlada. Não coloque chaves no frontend nem faça commit delas.

## Limites atuais

- Um agente trabalha diretamente no diretório `/workspace/repository`.
- Ainda não há isolamento por branch/worktree entre agentes simultâneos.
- O status é reconciliado quando a API recebe `GET /agents/:taskId/status`.
- Logs são obtidos de `tmux capture-pane`; uma etapa futura adicionará streaming/event bus.

## Próxima etapa: v0.7

A v0.7 deve adicionar Git Worktrees por tarefa, branches dedicadas, diff por agente, merge/reject e prevenção de alterações concorrentes no mesmo checkout.
