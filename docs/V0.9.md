# Oliveira DevCloud v0.9 — Review & Merge Orchestrator

A v0.9 adiciona uma etapa de integração humana antes do merge final.

## Fluxo

1. Codex e Claude trabalham em worktrees isolados.
2. A orquestração chega a `WAITING_REVIEW`.
3. `POST /api/v1/orchestrations/:id/review/analyze` cria uma branch temporária `review/<id>` em `/workspace/reviews/<id>`.
4. As branches dos agentes são mescladas apenas nessa worktree de review.
5. Conflitos são detectados sem tocar no checkout principal.
6. Quality gates allow-listed são executados sobre o código integrado, não sobre a branch principal antiga.
7. Somente um `ADMIN` ou `OWNER` pode aprovar o merge final.
8. A aprovação exige que `HEAD` da branch principal seja o mesmo commit usado como base da revisão e que o worktree principal esteja limpo.
9. Após o merge, worktrees e branches temporários são limpos e a operação é auditada.

## Estados de review

- `NOT_READY`
- `ANALYZING`
- `CONFLICT`
- `GATE_FAILED`
- `READY`
- `APPROVED`
- `REJECTED`
- `MERGED`

## Segurança

A v0.9 não aceita comandos arbitrários como quality gates. Os gates continuam limitados a comandos conhecidos, como `npm test`, `npm run build`, `npm run lint` e `npm run typecheck`. O review acontece em uma worktree temporária e o merge principal é bloqueado se a branch principal tiver avançado desde o início da análise.
