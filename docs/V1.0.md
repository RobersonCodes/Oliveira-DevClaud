# Oliveira DevCloud v1.0 — First Deployable Release

## Included
- AES-256-GCM Secret Manager with AAD-bound envelopes and masked API responses.
- Organization-scoped GitHub connection through encrypted `GITHUB_TOKEN`.
- GitHub repository browser and project import UI.
- Workspace repository bootstrap without embedding tokens in repository URLs.
- Host/platform resource summary endpoint.
- Production Docker Compose topology and HTTPS reverse-proxy template.
- All v0.2–v0.9 features: auth/RBAC, Docker workspaces, persistent terminals, browser IDE, previews, Codex/Claude tasks, worktrees, DAG orchestrator and review/merge gates.

## Security boundary
The Docker socket remains accessible only to the control-plane API/worker. Workspace containers do not receive it. Secret plaintext is decrypted only server-side and never returned by the secrets API. GitHub authentication is passed to Git as an ephemeral HTTP header rather than persisted in `.git/config` remote URLs.

## Before production
1. Generate a unique 32-byte master key and store it outside source control.
2. Use a dedicated Linux VM and firewall ports except 80/443/SSH administration.
3. Prefer a Docker socket proxy/rootless isolation before offering untrusted multi-tenant execution.
4. Replace static certificate mounts with Certbot/Caddy/Traefik automation.
5. Run Prisma migrations, tests, dependency audit and an external security review.
6. Back up PostgreSQL and workspace volumes; test restore procedures.

v1.0 is a deployable engineering baseline, not a claim that arbitrary public multi-tenant code execution is safe without infrastructure hardening.
